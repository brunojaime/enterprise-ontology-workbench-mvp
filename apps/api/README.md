# API

Adaptador HTTP del Enterprise Ontology Workbench. La lógica semántica reside en
los paquetes Python reutilizables y no en los endpoints FastAPI.

El contrato, límites, recarga segura y generación del cliente se documentan en
[`docs/api.md`](../../docs/api.md). En desarrollo, OpenAPI está disponible en
`http://localhost:8000/openapi.json`.
