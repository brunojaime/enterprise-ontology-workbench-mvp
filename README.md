# Enterprise Ontology Workbench MVP

Repositorio inicial de documentación para el MVP. Este bootstrap conserva el
paquete fuente, expone sus archivos extraídos y registra una evaluación de
readiness. No contiene implementación de la aplicación.

## Estado

La especificación y el backlog están listos para iniciar el Plan 00 de
alineación. La implementación funcional no comenzó y las decisiones pendientes
del Plan 00 deben cerrarse antes de avanzar al scaffold o al código de producto.
